# TextUtils

TextUtils is a simple authentication web application designed to provide a clean and easy-to-use login system.

## Features

- User Registration
- User Login
- Forgot Password
- Form Validation
- Responsive UI
- Frontend and Backend Integration

## Screens

### Register

Allows new users to create an account.

### Login

Allows registered users to securely log in.

### Forgot Password

Allows users to recover or reset their password.

## Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS

**Backend:** Node.js, Express.js

## Installation

```bash
npm install
npm run dev
```

## Project Purpose

This project was created to understand authentication flow, React frontend development, and communication between frontend and backend APIs.
